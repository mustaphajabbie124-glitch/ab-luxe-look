# AB Luxe Look – Frontend Learning Project

## About the Project

AB Luxe Look is a frontend web development project I built as part of my journey into web development.

The idea was to create a website concept for a fashion and beauty business. I used the name AB Luxe Look as a demo business identity to give the project a realistic purpose and allow me to practise building a website for a potential client.

The project was originally intended as a business website concept, but it has also become a valuable learning experience where I can practise, experiment, identify mistakes and improve my development skills.

This is an independent learning project, not an officially commissioned or launched business website.

## What I Practised

While working on this project, I gained practical experience with:

- Structuring web pages using HTML5.
- Styling layouts, sections and components with CSS3.
- Creating responsive layouts for different screen sizes.
- Using JavaScript to add interactive functionality.
- Building a mobile navigation menu.
- Creating an interactive image gallery with lightbox navigation.
- Integrating WhatsApp links for enquiries and booking requests.
- Organising project files and folders.
- Testing a website locally using VS Code and Live Server.

## Running the Project Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. View the website in your browser.
